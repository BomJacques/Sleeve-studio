Studio help

Start with an image

Drop a photo onto the canvas, use Upload image, or choose from the Studio collection. Open Cover layouts above the canvas, enter the album title and artist name, then choose a design. Layouts apply to square covers. The Listening size preview shows how the cover reads at 64 pixels. For a sharp export, start with an original at least as large as the target dimensions. Refresh clears the current cover and its saved edits. Uploaded images and fonts stay in your library.

Frame a cover or banner

Choose a format above the canvas. Fill crops to the edges. Fit keeps the whole image visible. Adjust Scale and drag the background to shift the crop. Turn on Guides to see the text area for that format.

Add a title or artist name

Click + beside Layers to add text, or select an existing text layer to edit it. Drag the text into place. In the Text inspector, choose a typeface, set a colour and add a drop shadow. Turn on Text outline to set its colour, width and corner style. Upload font accepts TTF, OTF, WOFF and WOFF2.

Adjust the image

Select Background in Layers. Use the Image inspector to rotate or flip the photo, pick a colour treatment, or adjust exposure and contrast. Set Image opacity to reveal the Canvas fill underneath. Open Object mask and click to keep connected areas of similar colour. Use the brushes for detailed fixes, adjust the edge shift and smoothing, then click Apply mask.

Export for your platforms

Open Export artwork and tick the destinations you need. One selection downloads an image. Several selections download together in a ZIP. Spotify artist headers use the background image only.
